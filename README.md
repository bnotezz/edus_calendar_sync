# 🎓 School Calendar Sync (Edus.school -> Google Calendar)

Автоматизований інструмент для синхронізації шкільного життя (портал **Edus.school**) із **Google Календарем**. Більше не потрібно заходити в додаток школи, щоб дізнатися розклад, кабінет, вчителя або що сьогодні на обід.

---

## ✨ Основні можливості

* 📚 **Розумний розклад:** Автоматичний імпорт усіх уроків із зазначенням вчителів та кабінетів на поточний та наступний тиждень.
* 🍽️ **Меню в кишені:** Інформація про страви (сніданки, обіди, полуденки, вечері) автоматично підтягується з меню їдальні та додається в опис відповідних подій.
* 🏖️ **Трекер канікул:** Автоматичне створення подій для канікул (осінніх, зимових, весняних та літніх) і державних вихідних із прозорим відображенням у календарі.
* 📍 **Автовизначення локації:** Назва та адреса школи автоматично підтягуються з налаштувань порталу та записуються в кожну подію календаря.
* 🎨 **Кольорове маркування:** Хешування ID предметів для стабільного та індивідуального забарвлення кожного уроку в календарі (11 кольорових категорій Google Calendar).
* 🏷️ **Візуальні Emoji-теги:** Швидке розпізнавання понад 20 предметів (🧮 Математика, 🇺🇦 Українська мова, 🇬🇧 English, 🔬 Science тощо).
* 🔐 **Smart Auth:** Автоматичний логін, отримання `UUID` учня та безпечна ротація JWT-токенів у GitHub Secrets без участі людини.
* 🔄 **Стійкість та дедуплікація:** Стабільні ідентифікатори слотів (`schYYYYMMDDn<num>`), що запобігають появі дублікатів і автоматично оновлюють скасовані або змінені уроки.
* 🛡️ **Захист від лімітів Google API:** Експоненційний Backoff для обробки помилок rate limit (HTTP 403/429) та конфліктів (HTTP 409).
* 🤖 **Повна автономність:** Працює через GitHub Actions — без необхідності тримати увімкнений комп'ютер чи орендувати сервер.
* 💓 **Моніторинг та алертинг:** Інтеграція з Healthchecks.io (heartbeats) та сповіщення в Telegram.
* ⚡ **Keepalive-захист:** Автоматичний коміт у службову гілку запобігає вимкненню за розкладом через 60 днів неактивності репозиторію на GitHub.

## 🚀 Швидкий старт

### 1. Підготовка Google Календаря
1. Створіть окремий Google Календар (наприклад, в акаунті дитини або спільний сімейний).
2. У [Google Cloud Console](https://console.cloud.google.com/) створіть проєкт, увімкніть **Google Calendar API** та створіть **Service Account**.
3. Згенеруйте та завантажте **JSON-ключ** сервісного акаунта.
4. Додайте `client_email` з цього JSON у налаштування доступу вашого Google Календаря з правами **"Внесення змін до подій"**.

### 2. Створення GitHub Personal Access Token (GH_PAT)
Оскільки CI-воркфлоу автоматично оновлює токени школи, йому потрібен дозвіл на запис у секрети репозиторію:
1. Перейдіть у **Settings > Developer settings > Personal access tokens > Fine-grained tokens** на GitHub.
2. Натисніть **Generate new token**.
3. У розділі **Repository access** оберіть **Only select repositories** і виберіть цей репозиторій.
4. У розділі **Permissions > Repository permissions** знайдіть **Secrets** і встановіть рівень доступу **Read and write**.
5. Згенеруйте токен і скопіюйте його (починається з `github_pat_`).

### 3. Налаштування GitHub Secrets
У репозиторії перейдіть до **Settings > Secrets and variables > Actions** та додайте секрети:

| Секрет | Опис | Обов'язковий |
| --- | --- | :---: |
| `GH_PAT` | Fine-grained токен GitHub для запису оновлених секретів | ✅ |
| `SCHOOL_HOST` | Адреса вашого порталу (наприклад, `https://demo.edus.school`) | ✅ |
| `SCHOOL_LOGIN` | Логін (email) батьківського акаунту від порталу | ✅ |
| `SCHOOL_PASSWORD` | Пароль батьківського акаунту від порталу | ✅ |
| `GOOGLE_CALENDAR_ID` | Email календаря (наприклад, `primary` або `xxx@group.calendar.google.com`) | ✅ |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | Повний вміст завантаженого JSON-ключа сервісного акаунта Google | ✅ |
| `TELEGRAM_BOT_TOKEN` | Токен бота від @BotFather для сповіщень про помилки | ⚪ |
| `TELEGRAM_CHAT_ID` | Telegram Chat ID від @userinfobot для отримання сповіщень | ⚪ |
| `HEALTHCHECKS_SCHEDULE_ID` | UUID пінгу Healthchecks.io для щоденного розкладу | ⚪ |
| `HEALTHCHECKS_HOLIDAYS_ID` | UUID пінгу Healthchecks.io для щотижневих канікул | ⚪ |

> **💡 Секрети `SCHOOL_TOKEN`, `SCHOOL_REFRESH_TOKEN` та `SCHOOL_USER_UUID`** вручну створювати **не потрібно**. Система автоматично виконає логін під час першого запуску, знайде профіль дитини та збереже токени у секретах.

## 💻 Локальна Розробка та Тестування

### 1. Встановлення середовища
```bash
# Клонування репозиторію
git clone <url-вашого-репозиторію>
cd edus_calendar_sync

# Створення віртуального оточення
python3 -m venv .venv
source .venv/bin/activate

# Встановлення робочих та dev-залежностей
pip install -r requirements-dev.txt
```

### 2. Конфігурація для локального запуску
Скопіюйте `.env.example` у `.env.local` (цей файл ігнорується гітом і захищений від витоків):
```bash
cp .env.example .env.local
```
Відкрийте `.env.local` та вкажіть дійсні або тестові значення.

### 3. Запуск скрипту локально
```bash
# Синхронізація розкладу уроків та меню
python sync.py --mode schedule

# Синхронізація канікул та вихідних
python sync.py --mode holidays
```

### 4. Запуск автоматичних тестів та лінтера
```bash
# Запуск тестів через pytest
pytest tests -v

# Або запуск через стандартний модуль unittest (без зовнішніх утиліт)
python3 -m unittest discover tests

# Перевірка покриття коду тестами (Coverage)
coverage run -m pytest tests
coverage report -m

# Перевірка відповідності PEP-8 через flake8
flake8 sync.py tests --max-line-length=130

# Перевірка свіжості бібліотек
pip list --outdated
```

## 🧩 Використання `EdusClient` як Окремого Компонента

Код взаємодії з порталом **Edus.school** виділено в окремий автономний модуль `edus_client.py`. Ви можете використовувати його у власних скриптах, Telegram-ботах або веб-сервісах без прив'язки до Google Календаря:

```python
from edus_client import EdusClient

# Ініціалізація клієнта
client = EdusClient(host="https://your-school.edus.school")

# Автентифікація (отримання JWT токенів)
auth_data = client.login("parent@example.com", "your_password")
access_token = auth_data["access"]
parent_uuid = auth_data["uuid"]

# Отримання профілю учня
students = client.get_parent_students(parent_uuid)
student_uuid = students[0]["user"]["uuid"]

# Отримання розкладу та меню
schedule = client.get_schedule(student_uuid, start_date="2026-10-20")
menu = client.get_canteen_menu()

print(f"Отримано уроків: {len(schedule.get('schedule', []))}")
```

## 📅 Графік роботи (Workflows)

Воркфлоу GitHub Actions налаштовано на два незалежні цикли:
1. **Щодня о 04:00 UTC:** Оновлення розкладу уроків та меню на поточний і наступний тиждень.
2. **Щонеділі о 05:00 UTC:** Оновлення даних про канікули, вихідні та семестри.
3. **Ручний запуск:** Вкладка **Actions > School Calendar Sync > Run workflow** (з вибором режиму: `schedule` або `holidays`).
